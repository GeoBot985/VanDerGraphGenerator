# Style Reference Samples

Place sample chart or diagram images here to use as style extraction references.

## How to use

1. Open the **Style Extraction** panel in Van Der Graph Generator.
2. Select an image from this folder (or any location on your computer).
3. Click **Extract Style** to analyse the image palette.
4. Review and edit the extracted style in the **Style Review** dialog.
5. Save the style profile for future use.

## Recommended image types

- Corporate report screenshots
- Dashboard screenshots
- Chart exports from other tools
- Presentation slides (exported as PNG)

## Notes

- Images are analysed deterministically using colour palette extraction.
- An optional vision-capable Ollama model can provide additional style hints.
- Only validated `StyleProfile` objects are saved — no executable code is ever generated from images.
- Extracted styles are approximate; review and edit before applying to production charts.
