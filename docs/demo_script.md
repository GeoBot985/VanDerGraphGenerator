# Demo Script

## 1. Launch

- Start the app with `python -m semantic_visual_builder`.
- Confirm the status panel shows startup checks and Ollama connectivity.

## 2. Load Data

- Use `File -> Load Sample Dataset` for the built-in transaction sample.
- Or load a CSV directly from disk.

## 3. Ask for a Visual

- Type a goal such as "Show transactions by region and status".
- Review the generated plan and validation output.

## 4. Preview

- Generate the preview and inspect the HTML export.
- If needed, open the export folder from the `View` menu.

## 5. Save and Reuse

- Save the recipe once the plan is valid.
- Load the recipe against another compatible dataset.
